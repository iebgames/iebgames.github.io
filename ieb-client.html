Product Overview

IEB Client is a comprehensive gameplay enhancement mod developed under the Forge API. Tailored specifically for Minecraft 1.8.9, the mod brings performance tweaks, graphical HUD customization, scripting extensions, and over 160 gameplay modules to enhance your standard sandbox experience. We focus on lightweight operations, ensuring that your frames per second (FPS) stay high while maintaining extensive feature coverage.

Whether you want to build structures faster, tweak combat mechanics, optimize entity rendering, or write custom JavaScript macros to automate routine game tasks, IEB Client provides a unified in-game control hub to do it all.

Key Features

  • 160+ Core Modules: Categorized into Combat (AimAssist, Velocity tweaks), Movement (BHop, Fly helpers), Render (ESP, Radar, Chams), and World automation (Scaffold, Nuker).
  • Scripting Engine (Nashorn): Write custom modules in JavaScript. Change player behavior, HUD widgets, or logic macros in real-time. Features a built-in code editor and hot reloading.
  • Custom HUD Design: Arrange your screen layout with dragging mechanics. Displays FPS, keystrokes, connection ping, inventory slots, coordinates, and system time.
  • Performance Boosters: Custom render algorithms that reduce memory usage, block out unnecessary packet calculations, and improve chunk loading speeds.

How to Install & Launch

Set up IEB Client in your Minecraft instance using these steps:

  • Ensure you have **Minecraft 1.8.9** installed with **Minecraft Forge (version 11.15.1.1722 or newer)**.
  • Download the latest **IEB-Client-v6.4.0.jar** file from our official GitHub release download link.
  • Open your computer's file explorer. Navigate to your Minecraft application directory (usually `%appdata%\.minecraft` on Windows or `~/Library/Application Support/minecraft` on macOS).
  • Copy and paste the downloaded `.jar` file into the **mods** folder inside your minecraft directory.
  • Start the Minecraft Launcher, select your Forge 1.8.9 profile, and click **Play**. In-game, press **Right-Shift** to toggle the client menu GUI!

Frequently Asked Questions

Q: Can I get banned on multiplayer servers for using IEB Client?
A: Yes. IEB Client includes automation and combat modules which are prohibited on competitive multiplayer servers. Always check the target server rules before connecting, and only use modules that are permitted. We are not responsible for account bans on third-party servers.
Q: Is IEB Client compatible with other mods like OptiFine?
A: Yes. IEB Client is designed to be fully compatible with OptiFine, NEI, and other standard 1.8.9 Forge mods. Simply place them together in the mods folder.
Q: Where can I find scripting documentation?
A: You can visit our dedicated client sub-site at **iebgames.github.io/ieb_client/docs/** where you can find detailed script guides, examples, and event APIs.
