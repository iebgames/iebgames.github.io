Product Overview

IEB-AI is an intuitive, fast, and feature-rich desktop client designed for artificial intelligence models. Rather than relying on heavy browser-based interfaces, IEB-AI sits comfortably on your machine, enabling rapid access to state-of-the-art language processing. Whether you need to generate high-quality copy, debug complex programming code, or translate documents across languages, IEB-AI streamlines the process.

Built under open-source licenses, IEB-AI is free of tracking and subscription walls. You have complete transparency over how the application communicates with API backends, keeping your API keys and local data private and secure.

Key Features

  • Flexible Model Support: Interface directly with OpenAI (GPT-4o), Anthropic (Claude 3.5), Groq (Llama 3), and custom local LLM servers running via Ollama.
  • Markdown Rendering: Beautiful, built-in styling for math symbols (LaTeX), structured tables, and programming code blocks with syntax highlighting.
  • System Prompts Directory: Build, save, and export custom role-playing prompt presets (e.g. Code Reviewer, Translator, SEO Optimizer).
  • Local Chat Archiving: Store logs on your hard drive in plain JSON formatting. Read or search past chats offline.

How to Install & Set Up

Getting started with IEB-AI is quick and direct:

  • Download the latest release executable or source code from our official download hub.
  • Extract the package to a folder of your choice on your system.
  • Launch the executable. Go to **Settings** and enter your preferred API key (or configure your Ollama endpoint: `http://localhost:11434` for local use).
  • Choose a model from the top dropdown and start asking questions!

Frequently Asked Questions

Q: Do I need a paid API key to use IEB-AI?
A: No! You can use IEB-AI completely offline and for free by integrating it with Ollama or local LLM instances. If you wish to use cloud models (like OpenAI or Anthropic), you will need to input your own API keys.
Q: Is my conversation data sent to IEB studio?
A: Absolutely not. All calls are made directly from your computer to the API provider (OpenAI, Groq, or your local machine). IEB Games has no middleman servers and collects zero chat metadata.
Q: Can I run custom local models?
A: Yes. Any API server conforming to the OpenAI Chat Completion specifications (such as LocalAI, LM Studio, or Ollama) is fully supported in the settings menu.
